## Career_AI (Active Repo)

**AI Resume & Career Advisor** — A multi-agent full-stack career platform:

- 🤖 **Autonomous Multi-Agent Architecture** — Specialized agents for resume analysis, ATS scoring, job matching, cover letters, mock interviews, career roadmaps
- 🎯 **ATS Compatibility & Metric-Driven Scoring** — In-depth parsing against industry standards
- 📄 **Interactive AI Resume Builder** — Live editor with templates, AI bullet rephrasing, PDF/DOCX export
- 🎙️ **Mock Interview Studio** — Voice synthesis (TTS), STAR-method evaluation, real-time grading
- 🗺️ **Personalized Career Roadmaps** — Multi-week visual skill progression plans
- 🧠 **Cross-Session AI Memory** — Persistent context across tools
- 📚 **Vector Grounded RAG** — Semantic retrieval over career rubrics & recruiter benchmarks

**Tech Stack:** React 19, TypeScript, Node/Express, Tailwind CSS v4, Google Gemini (`@google/genai`), ChromaDB
